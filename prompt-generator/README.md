# 킨더보드 프롬프트 생성기

주제를 입력하고 킨더보드 이미지 스타일 18종(v6.6) 중 하나를 고르면, 이미지 생성용 영문·한글 프롬프트를 만들어 주는 정적 웹 페이지입니다.

## 사용법

1. 주제를 입력합니다 (예: 사과를 든 토끼). 영문 주제와 추가 요청은 선택 사항입니다.
2. 스타일 카드를 고릅니다.
3. 생성된 프롬프트를 **영문 복사** 또는 **한글 복사**로 가져갑니다.

입력한 내용과 마지막으로 고른 스타일은 브라우저에만 저장됩니다.

## 파일 구성

- `index.html`: 페이지와 생성 로직
- `styles.js`: 18종 스타일 데이터 (이름, ID, 영문·한글 스타일 프롬프트, 샘플 이미지 경로)
- `images/`: 스타일별 샘플 이미지

스타일을 추가하거나 고치려면 `styles.js`를 수정하면 됩니다.

## 로컬 실행

`index.html`을 브라우저로 바로 열면 됩니다. 빌드 과정은 없습니다.

## 배포

GitHub Pages (`main` 브랜치 루트)로 배포됩니다.
