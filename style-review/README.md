# 스타일 마스터 검수

주제를 입력하고 킨더보드 이미지 스타일 중 하나를 고르면, 이미지 생성용 영문·한글 프롬프트를 만들어 주는 정적 웹 페이지입니다.

## 스타일 버전

상단의 버전 전환 버튼으로 두 세트를 오갈 수 있습니다.

- **v1 시트**: Google 시트 '시트2'의 13종 (`styles_v1.js`, 기본값)
- **v2 시트**: 기존 9종 (`styles.js`, 이전 18종 v6.6에서 선별)

## 사용법

1. 주제를 입력합니다 (예: 사과를 든 토끼). 영문 주제와 추가 요청은 선택 사항입니다.
2. 스타일 카드를 고릅니다.
3. 생성된 프롬프트를 **영문 복사** 또는 **한글 복사**로 가져갑니다.

입력한 내용과 마지막으로 고른 스타일은 브라우저에만 저장됩니다.

## 파일 구성

- `index.html`: 페이지와 생성 로직
- `styles.js`: v2 시트 9종 스타일 데이터 (이름, ID, 영문·한글 스타일 프롬프트, 샘플 이미지 경로)
- `styles_v1.js`: v1 시트 13종 스타일 데이터 (같은 형식)
- `images/`: 스타일별 샘플 이미지

스타일을 추가하거나 고치려면 해당 버전의 데이터 파일을 수정하면 됩니다.

## 카드 이미지 추가·삭제

스타일 카드에서 **+ 이미지 추가**로 예시 이미지를 넣고, 각 이미지의 **×**를 두 번 눌러 삭제합니다. 기본 샘플은 숨김 처리되어 **숨긴 샘플 복원**으로 되돌릴 수 있습니다. 추가·삭제 내역은 그 브라우저에만 저장되고 저장소 파일은 바뀌지 않습니다. 이미지의 **↓**로 한 장씩 내려받을 수 있습니다.

## 로컬 실행

`index.html`을 브라우저로 바로 열면 됩니다. 빌드 과정은 없습니다.
